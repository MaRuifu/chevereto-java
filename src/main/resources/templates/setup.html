chevereto-java

首次安装

为本站选择数据库，只需选择一次。配置写入 ./data/instance.properties，之后启动不再询问。

内置 H2 推荐

数据存于 ，零依赖、立刻可用。 适合单机与小流量站点；随程序目录一起备份即可。

MySQL

指向已有 Chevereto 生产库即可无缝接管：只补建缺失的表，不改动、不清空、不覆盖任何现有数据。 目标库需事先创建：CREATE DATABASE 库名 DEFAULT CHARSET utf8mb4;

两种方式都会建立 chv_ 前缀的 29 张表，表名 / 列名 / 类型与 Chevereto 官方生产结构逐列一致，可与原版互相迁移。
