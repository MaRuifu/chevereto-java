洪水保护

同一 IP 在时间窗口内上传过多图片时拦截后续上传（管理员不受限制）。 键名与默认值完全对齐原版 flood_uploads_*。

收件地址取「邮箱」页的「收件箱」，同一窗口内只通知一次。

各时间窗口上限

填 0 表示该窗口不限制（与原版一致）。判定按「达到即拦截」，即窗口内最多成功上传 N 张。 窗口是滚动窗口（最近 1 分钟 / 1 小时 / 24 小时 / 7 天 / 1 个月），不是自然日。

登录 / 注册失败限流

与原版一致：同一 IP 在最近 24 小时内「登录 + 注册」失败累计 超过 25 次会直接返回 403（硬编码阈值，不在设置里）； 达到验证码阈值则优先要求人机验证。
